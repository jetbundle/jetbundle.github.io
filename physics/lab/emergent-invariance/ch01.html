chapter 1 — symbolic structure, logic, and combinatorial compression

foundations: encode astronomically large configuration spaces with precise symbolic tools

1.1 sets and sample space

a set collects distinct objects (elements). the sample space $S$ (also $\Omega$) lists all microstates — one complete specification of the system. an event is any subset $A \subseteq S$. a $\sigma$-algebra is a family of subsets closed under complement and countable unions and intersections; it is the bookkeeping needed before measure and probability become rigorous.

example (two fair coins). $S=\{HH,HT,TH,TT\}$. the event “at least one heads” is $\{HH,HT,TH\}$.

1.2 mappings and equivalence classes

a mapping $f:S\to T$ assigns exactly one output in $T$ to each input in $S$. permutations are bijections $S\to S$. when microstates are physically indistinguishable, partition $S$ into equivalence classes; counting distinct classes is the statistical weight $\Omega$.

1.3 combinatorics — counting microstates

permutations of $n$ distinct objects: $n!$. combinations (“choose $k$ of $n$”): $$\binom{n}{k}=\frac{n!}{k!(n-k)!}.$$

multinomial coefficient. partition $N$ objects into groups of sizes $n_1,\dots,n_r$ with $\sum_i n_i=N$. the number of distinct assignments is $$\frac{N!}{n_1!\,n_2!\cdots n_r!}.$$ this is the multiplicity for distributing $N$ labeled objects into labeled bins; indistinguishability modifies the story exactly through these factorial corrections.

1.4 induction and summation

induction proves $P(n)$ for all integers $n\ge 1$: base case $P(1)$, then $P(k)\Rightarrow P(k+1)$. summation $\sum_{k=1}^n a_k$ packages finite totals. generating functions encode sequences as formal power series; the equilibrium partition function $Z=\sum_i e^{-\beta E_i}$ is the flagship generating functional for thermodynamic observables.

1.5 stirling preview

for large $N$, factorials dominate naive numerics. stirling’s leading logarithm is $$\ln N! = \sum_{k=1}^N \ln k \approx N\ln N - N.$$ chapter 2 re-derives this picture by comparing the sum to a Riemann integral of $\ln x$.

1.6 expectation and the partition function

let $p(x)$ be probabilities over microstates with $\sum_x p(x)=1$. the expectation of a quantity $f$ is $$\mathbb{E}[f]=\sum_x f(x)\,p(x).$$ the canonical partition function (discrete spectrum) is $$Z(\beta)=\sum_i e^{-\beta E_i}, \qquad \beta=\frac{1}{k_{\mathrm{B}}T}.$$ it normalizes the gibbs weights $p_i = Z^{-1} e^{-\beta E_i}$ and generates averages via derivatives of $\ln Z$.

1.7 bridge summary

  • discrete symbolic tools $\to$ continuous integrals (ch.2)
  • combinatorial constraints $\to$ symmetries and quotient spaces (ch.5)
  • sums and generating functions $\to$ $Z$ for the rest of the spine

1.8 worked problems (condensed)

problem 1 (multinomial microstates). $N$ indistinguishable particles occupy energy bins with occupancies $n_i$, $\sum_i n_i=N$. if particles were distinguishable there would be $N!$ assignments; dividing by $\prod_i n_i!$ removes permutations inside each bin, giving $\Omega=\frac{N!}{\prod_i n_i!}$. fixing total energy $E=\sum_i n_i\varepsilon_i$ turns counting $\Omega(E)$ into a constrained composition problem — the microcanonical weight.

problem 2 (stirling via integrals — sketch). because $\ln x$ is increasing, $$\int_1^N \ln x\,dx < \sum_{k=1}^N \ln k < \int_1^{N+1}\ln x\,dx.$$ with $\int \ln x\,dx = x\ln x - x$, both bounds behave as $N\ln N - N$ at leading order.

problem 3 (two-state paramagnet). single spin energies $\pm \mu B$ give $z=e^{\beta\mu B}+e^{-\beta\mu B}=2\cosh(\beta\mu B)$. $N$ independent spins factor: $Z=z^N$. helmholtz free energy $F=-k_{\mathrm{B}}T\ln Z$; average energy $\langle E\rangle=-\partial_\beta \ln Z = -N\mu B\tanh(\beta\mu B)$.
